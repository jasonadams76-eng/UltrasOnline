# Ultras History content

* `volumes.json` — volumes, missions (story text), roll call, which people appear where, and Open Threads.
* `people.json` — villains and allies. An entry with `contactId` reuses a contact already in the game (Victor Cross, Frankie Vega, Blackwell, Stone) and adds status and story. Other entries carry the full sheet.

Images (all optional; a plain card shows if missing):
* `images/history/<volumeId>.jpg` — volume banner (`shadows_infinite`, `havoc_unleashed`)
* `images/history/<missionId>.jpg` — mission card/page image (`si1`..`si3`, `hu1`..`hu4`)
* `portraits/<person portrait id>.jpg` — e.g. `villain_lynx.jpg`
